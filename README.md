# Personal Finance Manager

## 📌 Project Description

Personal Finance Manager is a simple Python console application that helps users manage their personal finances. Users can record income and expenses, view all transactions, check their current balance, and visualize financial data using charts.

---

## ✨ Features

- Add Income
- Add Expense
- View All Transactions
- Check Current Balance
- Expense Distribution (Pie Chart)
- Income vs Expense Comparison (Bar Chart)
- Store data using CSV file

---

## 🛠 Technologies Used

- Python
- CSV Module
- Matplotlib
- Datetime Module
- OS Module

---

## ▶️ How to Run

1. Install Python.
2. Install matplotlib.

```
pip install matplotlib
```

3. Run the program.

```
python finance_manager.py
```
